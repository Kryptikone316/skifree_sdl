SkiFree Modern (16-bit) art module (optional)
=============================================

Sprites for the Modern (16-bit) theme: 84 images drawn for this port, the same sizes as the game's own so
collisions do not change.

Install: unzip into the port folder, roms/ports/skifree/, so the files end up in roms/ports/skifree/sprites16/.
Without this module the Modern (16-bit) theme still has its menus and snow ground, but the game is drawn with
the game's own sprites. Any file you leave out falls back to the game's own sprite.

The art is under the MIT license (LICENSE.txt in this folder).
