SkiFree Modern (8-bit) art module (optional)
============================================

Sprites for the Modern (8-bit) theme: the 16-bit art reduced to half resolution (2x2-pixel blocks, the same
sizes as the game's own) in one fixed 36-colour palette. It works on its own; the 16-bit module is not needed.

Install: unzip into the port folder, roms/ports/skifree/, so the files end up in roms/ports/skifree/sprites8/.
Without this module the Modern (8-bit) theme still has its menus and snow ground, but the game is drawn with
the game's own sprites. Any file you leave out falls back to the game's own sprite.
