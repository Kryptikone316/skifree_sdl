SkiFree sound module (optional)
===============================

The nine built-in game sounds (crash, jump, woof, land, board, bump, gobble, piddle, roar), made for this port.

Install: unzip into the port folder, roms/ports/skifree/, so the files end up in roms/ports/skifree/sounds/.
Without this module the game is silent. Your own replacements go in roms/ports/skifree/gamedata/sounds/custom/
(see the README there) and work with or without this module.
